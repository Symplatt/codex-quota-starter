# 额度启程 · Quota Starter

当前版本：1.5.13

Quota Starter 是一个 Windows 后台工具，用于查看 ChatGPT Plus 的 Work / Codex 共享额度，并在额度刷新后尝试发送一次简短请求。你也可以选择希望的刷新时间，由软件提前五小时安排请求。

软件提供中文本地网页界面，支持自动检测、定时刷新、暂停运行和登录自启。关闭网页后，后台仍会继续运行。

## 安装

### 1. 准备运行环境

需要 Windows、Python 3.11 或更高版本，以及官方 Codex CLI。安装程序不会自动安装这些依赖。

1. 从 [Python 官网](https://www.python.org/downloads/windows/) 安装 Python，安装时勾选 **Add python.exe to PATH**。
2. 从 [Node.js 官网](https://nodejs.org/) 安装 LTS 版本，它包含 npm。
3. 打开 PowerShell，依次运行：

   ```powershell
   npm install -g @openai/codex
   codex login
   ```

4. 按浏览器提示，使用你的 **ChatGPT Plus 账户**完成登录。已有上述环境且已登录的用户可直接下载安装包。

### 2. 下载并安装

1. 打开 [最新版下载页](https://github.com/Symplatt/codex-quota-starter/releases/latest)。
2. 在 **Assets** 中下载 `quota-starter-版本号-windows.zip`，不要选择 `Source code`。
3. 右键 ZIP，选择 **全部解压**。
4. 打开解压后的 `quota-starter` 文件夹，双击 **Install.cmd**，等待安装完成。不要直接从压缩包窗口运行。
5. 双击桌面或开始菜单中的 **Quota Starter**，打开软件界面。

默认安装位置为 `%LOCALAPPDATA%\Programs\QuotaStarter`，安装后会在登录当前 Windows 用户时自动启动。当前使用脚本安装，没有 EXE 安装向导。仅解压文件不代表已安装成功；安装报错时请保留窗口中的错误信息。

### 从旧版本升级

下载新版 Windows ZIP，完整解压后运行新版 **Install.cmd** 即可覆盖安装，无需先卸载。安装会刷新程序缓存，已有历史记录、时间计划、暂停状态和自启设置会保留。

## 开始使用

通过 **Quota Starter** 快捷方式打开界面；后台运行时也可访问 [本地页面](http://127.0.0.1:8769)。主页显示五小时和长周期剩余额度、服务器报告的刷新时间、请求计划及最近的运行记录。“触发记录”与“操作与连接日志”位于两个独立卡片，点击两张卡片标题可平滑滚动到相应位置，日志滚动区最高520像素，单独显示最近50条操作及故障记录，包含计划设置、修改、取消和原/新时间，重新检测、重连、暂停/恢复、自启操作及连接恢复结果；每分钟的检测不会挤掉这些记录，原检测明细仍可展开。所有时间按北京时间显示。连接成功时，右上角显示“后台运行”。

正常连接时，每轮检测或发送结束后等待60秒再自动检测，临近或越过刷新时间也不加快频率。手动“重新检测”和“重新连接”立即执行，成功后恢复60秒间隔；失败重试仍间隔10秒。时间计划在到点后的下一轮自动检测中处理，保存或取消计划不会额外触发检测。如果当前窗口已经有实际使用，软件通常跳过额外请求；暂停状态下需要点击 **恢复运行** 才会继续发送。

| 操作 | 用途 |
| --- | --- |
| 选择时间 | 设置希望的刷新时间，软件自动提前五小时安排请求 |
| 恢复自动 | 取消手动计划，重新按服务器报告的刷新定时刷新 |
| 重新检测 | 只重新读取当前额度和服务器刷新时间，不发送小额请求，不提前执行时间计划；暂停时也可使用 |
| 重新连接 | 清除连接重试计数，先连接并读取额度，再交回后台调度；网络故障会自动重连，也可手动立即重连；暂停设置与发送记录保留 |
| 暂停 / 恢复运行 | 控制是否发送请求；暂停时仍检测额度，已提交的请求可能继续完成 |
| 开机自启动 | 在页面下方设置登录 Windows 后是否启动；关闭此开关不会停止当前后台 |

定时刷新与运行状态卡片统一在标题右侧显示操作按钮；标题字号较大，窄窗口自动将按钮换到标题下方。并排时卡片等高，底部分隔线对齐。运行状态按钮从左到右为绿色“重新检测”、“重新连接”和“暂停 / 恢复运行”。定时刷新使用固定长度的横向时间轴，上方显示额度刷新与预计再次刷新，下方显示发送请求，每个事件保留北京时间和日期；等待超过五小时时以断轴符号省略部分距离，短间隔按比例显示，相邻事件保留最小可见间距。时间轴带尺子式长短刻度，整点用灰色小字标注；断轴省略中间时段，窄窗口自动减少整点标注以避免重叠。并排时定时刷新卡片较宽，运行状态以上下两行显示检测时间；底部保留简要状态，鼠标悬停可查看完整原因，操作结果显示在页面右下方，成功提示3.5秒后关闭，错误提示7秒后关闭。窄窗口自动上下排列，并按内容收紧卡片高度。

### 设置刷新时间

点击 **选择时间**，窗口提示“选择**完成刷新**的时间”。输入年、月、日、时、分，或滚动各列选择数值（滚轮响应间隔由90毫秒缩短至30毫秒），然后点击 **确定**。秒固定为 `00`。取消、按 Esc 或点击弹窗外侧不会保存。

例如，选择 10 月 11 日 12:00 刷新，会安排 10 月 11 日 07:00 发送请求。主页时间轴显示服务器额度刷新、请求发送和预计再次刷新的时间。

不可用时间会灰置：推算出的发送时间须晚于当前时间和最近检测到的服务器刷新时间，且不早于防重复保护结束时间，并在未来 366 天内。未检测到服务器刷新时间时，选择按钮不可用。

每次定时检测、重新检测、重新连接及发送前校验都会检查计划：服务器刷新时间达到或超过计划发送时间时，自动取消该任务，恢复自动安排并记录取消原因。启动时会依据已有额度快照清理旧版本留下的无效计划，无需恢复连接。

到点发送仍须满足额度、暂停状态及防重复条件。睡眠、关机或断网可能造成延迟；预计刷新时间按发送时间加五小时计算，实际刷新以服务器返回为准。

## 运行条件与请求开销

软件使用已登录的官方 Codex CLI 读取额度并发送简短请求，不使用 API Key。发送会消耗订阅内额度，实际开销以记录为准；短提示词仍可能包含官方运行时添加的上下文。

软件不会增加总配额、突破五小时或每周限制、购买积分或使用额度重置券。额度不足、登录不符合要求或额度信息无法确认时，不会发送。

请求已能实际完成，但“刷新后的首次请求是否决定下一轮五小时起点”尚未完成跨自然刷新边界的验证，因此不能保证按所选时间刷新。机制依据见 [机制说明](MECHANISM.md)，已有测试见 [验证记录](VALIDATION.md)。

自动运行需要电脑开机并登录当前 Windows 用户。锁屏时可继续运行；休眠、关机或断网时无法发送。无需一直打开网页或 Codex 桌面窗口。

每轮连接、检测或发送最多尝试5次（含首次），失败后间隔10秒，从首次尝试起最多1分钟。检测遇到临时网络故障时，短时重试达到上限后，每20分钟自动尝试一次恢复连接（每小时三次），每次最多等待60秒，失败后不再叠加五次快速重试；重启保留等待时间，休眠错过的尝试不补跑。恢复后先只读取额度，60秒后的下一轮检测再处理仍有效的到期计划。身份、额度数据等非网络错误，以及结果未知的发送达到重试上限时仍停止，须点击“重新连接”。小额请求重试前重新检查额度，结果未知的重试可能产生额外用量；每轮发送记录保留，手动重连不清除周期防重复记录。暂停会停止等待中的发送重试。

连接完成后即更新额度，另行显示准备、发送及核验请求的状态。重新检测在后台执行，不等待小额请求完成；自启动状态查询不会阻塞额度显示。

软件为自己的 Codex 子进程启用系统代理跟随，不修改电脑或 Codex 全局配置；账户或额度读取发生网络故障后，下一次短时重试会重建子进程，重新取得网络路由。额度读取不再额外查询重置券详情。请求已确认成功后，后续额度核验超时仍按可恢复的连接故障处理，不误判为发送结果未知。

## 停止与卸载

- **暂时停止发送**：在页面点击“暂停”，状态在重启后保留。
- **停止当前后台**：运行安装目录的 `Stop.ps1`；自启开启时，下次登录仍会启动。
- **取消自启并停止后台**：运行 `Uninstall-Autostart.ps1`。
- **卸载**：运行 `Uninstall.ps1`，移除自启及快捷方式。程序文件与数据会保留，需要彻底删除时，再自行删除安装目录。

将 `%LOCALAPPDATA%\Programs\QuotaStarter` 粘贴到文件资源管理器地址栏即可打开安装目录。右键所需 `.ps1` 文件，选择“使用 PowerShell 运行”。执行策略阻止脚本时，可在该目录打开 PowerShell，运行以下命令，将文件名替换为所需脚本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Stop.ps1
```

该命令只影响当前进程，不修改系统全局执行策略。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 安装提示找不到 Python 或 Codex | 检查依赖安装，重新打开 PowerShell，执行 `python --version` 和 `codex --version` |
| 页面打不开 | 从快捷方式重新启动，检查安装目录的 `data\supervisor.log`；确认本地端口 8769 未被占用 |
| 提示不是 ChatGPT Plus 登录 | 用 `codex login status` 检查登录，运行 `codex login` 登录 Plus 账户 |
| 无法获取额度 | 检查网络与官方服务；网络故障后每20分钟自动重连一次，也可点击“重新连接”立即重试 |
| 到点仍未发送 | 检查暂停状态、每周额度和防重复记录；服务器仍报告额度用尽时会继续等待 |
| 提示轻量模型不可用 | 更新官方 Codex CLI 后重新检测；软件不会自动切换到高消耗模型 |
| 登录后没有自启 | 检查页面自启开关和 Windows 任务计划程序中的 `QuotaStarter-WorkCodex`；确认 Python 未被移动或删除 |
| 无法设置自启 | 检查是否受 Windows 或企业策略限制，保留安装错误信息 |

进一步诊断：在安装目录打开 PowerShell，运行 `python -X utf8 diagnose.py`，该命令不发送请求。提交问题前请检查日志，移除不希望公开的信息。

## 数据与隐私

配置及运行记录保存在安装目录的 `data` 中，数据库为 `quota.sqlite3`，记录额度快照、请求状态、时间、回复、用量及账户标识的哈希。覆盖升级保留此目录。

登录由官方 Codex CLI 管理，软件不复制或上传登录凭据。它读取本机 Codex 配置中的 MCP 名称，为自己的运行进程关闭相关集成，不修改原配置。本地页面只监听本机地址 `127.0.0.1`。

公开仓库和安装包不包含本机数据库或账号资料。

### 完整日志文件

点击“操作与连接日志”卡片右上角的“打开日志文件夹”可直接打开存储目录。日志固定保存在 `%LOCALAPPDATA%\Programs\QuotaStarter\data\logs`，按北京时间月份自动创建 `quota-starter-YYYY-MM.jsonl`，每行一条完整事件，包含检测、操作、连接和触发详情。旧月份文件保留，升级时补录数据库中仍保留的历史。使用自定义 `--data` 时保存在该目录的 `logs` 下。写入失败时保留数据库记录并自动重试；异常断电发生在写入和进度保存之间时，可能出现相同事件 ID 的重复行。
