# Quota Starter 1.6.0 更新日志（审核候选）

日期：2026-10-23。以1.5.23为连接基线；本文件按新流程在审核前保存。项目CHANGELOG保留仓库现有历史，审核通过后同步。本次未正式构建、覆盖安装或发布。

## Added

- [x] 时间轴发送节点支持十分钟步长拖动、方向吸附与左右方向键，松开保存；弹窗仍支持整分钟。
- [x] 按账户和分钟保存额度采样，显示最近一小时、五小时或二十四小时折线；缺测留空，统计选框长期记忆。
- [x] 增加暂停期间只读检测开关，默认关闭；开启后继续采样，不发送小额请求，重启保留设置。
- [x] 周额度显示预计更新时间：首次五小时剩余100%记录，此后仅在不足100%恢复100%时更新，按账户保存。
- [x] 增加只显示当前错误的横幅和浏览器标签页额度图标；错误显示不增加CLI检测或改变错误处理。

## Changed

- [x] 独立触发记录并入日志，补入尚未写最终事件的请求并按attempt去重；统一月度日志保留本月、上月、上上月，旧文件校验备份后合并。
- [x] 两条周期验证提示明确说明刷新时间未变或观察到五小时倒计时；原数值判定条件不变。
- [x] 统计、日志、滚动条及两行悬浮标签按差异文档移植；暂停时显示“停止运行”。
- [x] “恢复自动”可用时与“选择时间”文字样式一致；只有统计卡动态调整高度，使首屏和下方20px留白合计100vh。
- [x] 全部本次差异、完整HTML和连接基线校验统一保存在“差异文档/1.6.0”。

## Fixed

- [x] 既有重连或恢复成功读取后，计划发送时间严格早于五小时刷新时间时恢复自动并提示；核验这轮不发送请求。
- [x] 统计卡不再因剩余高度不足140px或宽度不超过1000px而放弃适配；其他固定内容不被压缩。
- [x] HTTP测试的会话令牌提取兼容格式化后的空白及单双引号，应用原有Host/Origin/token验证保留。
