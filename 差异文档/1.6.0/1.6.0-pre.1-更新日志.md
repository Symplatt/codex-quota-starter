# Quota Starter 1.6.0-pre.1 更新日志

日期：2026-10-23。用户已批准先发布预发布版本；正式版保持1.5.23。

本版本为1.6.0预发布，正式版仍为1.5.23。连接、CLI选择、代理、RPC参数、超时、重试与恢复实现保持1.5.23原样，默认端口8769。

### Added
- [x] 时间轴发送节点支持十分钟步长拖动、按方向吸附及左右方向键，松开保存；时间弹窗仍支持整分钟。
- [x] 按账户和分钟持久保存额度采样，支持一小时、五小时和二十四小时折线；缺测留空，统计选框在当前浏览器长期记忆。
- [x] 增加暂停期间只读检测开关，默认关闭；开启后继续检测和采样，不发送小额请求。
- [x] 周额度显示预计更新时间：首次检测到五小时剩余100%时记录，此后仅在不足100%恢复100%时更新；按账户保存，未检测到时显示待检测。
- [x] 增加当前错误横幅及浏览器标签页额度图标；横幅只显示已有错误，不增加CLI兼容诊断或改变错误处理。

### Changed
- [x] 独立触发记录并入最近50条日志，补入未写最终事件的请求并去重；月度日志保留本月、上月和上上月，旧文件校验备份后合并。
- [x] 周期验证提示明确说明刷新时间未变或观察到五小时倒计时，原数值判定条件不变。
- [x] 日志卡加上下留白占满一屏；页面和日志使用细滚动条，统计悬浮标签分为日期时间与额度变化两行；暂停时显示“停止运行”。
- [x] 有计划且可用时，“恢复自动”与“选择时间”的文字样式一致。
- [x] 软件标题、上方两张卡和留白保持既定尺寸，仅统计卡动态调整高度，使首屏和卡片下方20px留白合计100vh。

### Fixed
- [x] 既有重连或恢复成功读取后，计划发送时间早于五小时刷新时间时恢复自动并在右下角提示；核验这轮不发送小额请求。
- [x] 统计卡不再因剩余高度不足140px或窗口宽度不超过1000px而放弃首屏适配；窄屏固定内容超出可视区时保留滚动。

已通过163项Python及42项前端测试。真实五小时及周额度自然恢复边界尚未完成长时观察；预发布不承诺所选时间一定成为服务器刷新时间。
