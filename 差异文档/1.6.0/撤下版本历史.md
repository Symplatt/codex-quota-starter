# 撤下版本的历史更新记录

2026-10-23 用户要求正式 Release 仅保留到1.5.23，并发布1.6.0预发布。以下保留原CHANGELOG，作为撤下版本的历史，不代表当前版本行为。旧Tag和提交历史保留。

## [1.7.0] - 2026-10-21

### Added
- 浏览器标签页增加绿色额度图标。
- 设置增加“关闭软件后依然每分钟检测额度变化”，默认关闭；开启后暂停期间继续只读检测和折线采样，重启保留，手动检测及重连始终可用。

### Changed
- 删除独立触发记录卡，将小额请求结果、周期验证和待核实请求合并到“日志”；定时额度读取不进入页面日志列表，额度检测、操作、连接和触发记录合并为每月同一份JSONL，页面隐藏的每分钟检测照常写入；旧触发归档去重迁移并校验保存原档备份。
- “操作与连接日志”改名“日志”，卡片高度加上下各20像素留白占满一屏，点击标题平滑定位，记录独立滚动且自动刷新保留滚动位置。
- 统一卡片横纵间距为20像素，标题与右侧操作控件居中对齐，页面与日志改用细滚动条；日志三列统一行高、顶部内边距及顶端对齐。
- 额度变化统计标题与图表之间留白增加至24像素；悬浮标签固定两行，第一行日期时间，第二行剩余额度和变化，消耗/恢复的百分点不显示小数。

### Fixed
- 时间轴发送节点在检测、连接及禁用拖动时仍保持不透明墨绿色。
- Codex 子进程在启动及重连前明确继承当前启用的 Windows 代理，避免桌面启动时缺失或沿用过期代理；支持显式代理覆盖，保留本机地址直连。
- 优先使用 npm 安装的官方 CLI，避免桌面附带的预览版在 PATH 中抢先被选中。
- 账户与额度读取发生临时网络错误时，在同一重试轮内复用健康连接，避免第二次错误就冷启动导致剩余时间不足；进程退出、RPC 超时或整轮耗尽仍关闭，保留5次/60秒及20分钟恢复规则，重连成功写入日志。
- 只读额度及账户接口的 HTTP 408、425、429、500、502、503、504 纳入自动恢复，修复这些临时服务错误可能导致永久停止的问题；认证失败、账户异常和未知发送结果仍保留停止保护。

## [1.6.2] - 2026-10-20

### Fixed
- 额度变化统计的时间范围和额度类型长期保存到当前浏览器，刷新、关闭并重新打开页面后恢复上次选择；无效或不可用的存储不影响页面运行。

## [1.6.1] - 2026-10-20

### Changed
- 正式后台、启动检查、桌面快捷方式打开地址及连接诊断统一默认使用8770端口，保留已有数据、计划与自启偏好。

### Fixed
- 修复删除统计图例时CSS选择器误合并，导致统计标题区域被设为180像素并拉伸的问题；标题保持正常高度，图表使用卡片内剩余空间，上方两张卡片不变，整体仍精确占满首屏100vh。

## [1.6.0] - 2026-10-20

### Added
- 触发记录增加“打开文件夹”，按月保存完整额度读取与小额请求结果，与日志同样仅保留本月、上月、上上月；升级补录数据库保留的历史，失败重试。
- 支持拖动时间轴“发送请求”圆点，以十分钟为一格设置计划；非整十分钟时间首次按拖动方向吸附，松开保存，并支持左右方向键。
- 在概览区下方、触发记录上方增加通栏额度变化统计，以细折线显示每分钟剩余额度，支持五小时/周额度及一小时/五小时/二十四小时范围；坐标刻度随范围和数据调整，曲线穿过真实采样点，快速消耗通过真实陡降体现，曲线始终为墨绿色，不显示图例或变色，采样持久保存、缺测留空。

### Changed
- 暂停时右上角状态胶囊显示“停止运行”；只有正常连接运行时显示“后台运行”，连接中、等待重连及断开保留对应状态。
- 统计卡高度根据网页实际可视区域动态计算，使软件标题、上方两张卡片、统计卡及其下方间隔恰好占满100vh，触发记录从下一屏开始，上方两张概览卡片布局不变；删除统计底部已记录分钟数和消耗/恢复汇总文字。
- 触发记录仅展示按时间排序的最近15条；触发记录与操作日志均支持整行悬停高亮，时间列同为175像素。
- 额度变化统计标题支持平滑滚动；点击统计、触发记录、操作与连接日志标题后统一保留12像素顶部间距，较之前多滚动12像素，上方卡片底边完全移出视野。
- 月度日志按北京时间只保留本月、上月和上上月，每月1日清理更早文件；错过月初时补清理，失败重试，过期历史不重新归档。
- 将“重新检测”、“重新连接”、“暂停 / 恢复运行”的可用文字改为灰绿色，保留禁用状态区别。
- 触发记录区分每分钟额度读取和小额请求；分别显示获取额度、刷新时间不变（相差≤5秒）和成功进入五小时倒计时的文案，保留异常核验结果及历史原始证据。
- README 与内置帮助补充拖动、统计、日志保留和请求交互说明，README 增加开发技术及验证、打包命令。

## [1.5.24] - 2026-10-19

### Fixed
- Codex CLI 不支持额度读取接口或参数时，明确提示当前 CLI 版本、实际程序路径与升级命令，立即停止无效重试，升级后可手动重新连接。
- 页面标题下方增加仅在发生错误时显示的横幅，呈现连接、CLI 兼容性、自启和操作错误，恢复正常后自动隐藏。
