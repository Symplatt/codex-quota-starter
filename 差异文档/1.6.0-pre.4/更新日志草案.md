# Quota Starter 1.6.0-pre.4 更新日志

日期：2026-10-23；状态：用户审核通过，覆盖安装核验通过，正在发布。

## Added

- [ ] 在“额度变化”下新增横跨内容区的“预设任务”卡片，支持指定精确到秒的北京时间，或五小时额度回满后执行。
- [ ] 支持填写内容生成独立 MD、读取已有 UTF-8 MD、自选路径及默认目录；任务保存创建时内容，不覆盖原文档。
- [ ] 默认任务目录为 %LOCALAPPDATA%\QuotaStarter\tasks，首次使用时自动创建；可自选目录，清空设置恢复默认。
- [ ] 默认提供 GPT-6 Astra、GPT-6.1 Sol，检测本机 Codex 其他模型后以标签复选；提供 low、medium、high、xhigh、max、ultra 六档强度并在执行前核验。
- [ ] 任务持久化排队执行，独立更新等待、执行、完成、失败、取消状态；支持实时回复、详情、取消、中断及独立结果 MD，不影响每分钟额度检测。
- [ ] 新增右侧定时刷新、额度变化、预设任务、日志、设置五节点进度导航。

## Changed

- [ ] 新建任务窗口中模型与推理强度位于开始方式、开始时间上方；字段小标题加粗，纵向行间距增加至26px。
- [ ] 任务列表的模型与强度独立成列，状态仅保留右侧胶囊；胶囊与任务设置按钮右对齐，详情相对新建任务按钮右边缘向左移动6px作视觉对齐。
- [ ] 详情中的任务及结果文档位于执行目录内时，省略执行目录前缀为“...\相对路径”；悬停可查看完整路径，目录外仍显示绝对路径。
- [ ] 详情状态胶囊移至标题右侧，与标题等高，文字较小且水平、垂直居中；去掉重复状态，保留具体执行进度和失败原因。
- [ ] 标题下方仅显示“任务状态每 2 秒更新”，标题区与任务列表间距增加至28px。
- [ ] 定时刷新节点返回整页最顶部；中间卡片定位保留顶部20px留白；设置卡片仅滚动到自然底部，不增加底部占位，窄窗口隐藏侧边节点。
