选择时间

点击按钮打开弹窗，可在年、月、日、时、分五个独立输入栏中直接输入时间；也可将鼠标悬浮在年、月、日、时、分上滚动滚轮，或直接点击数值。按北京时间设置，秒固定为 00；灰色时间不可选。点击“确定”后，软件按刷新时间减五小时安排小额请求。取消、点击外侧空白或按 Esc 不会保存。

拖动时间轴

左右拖动“发送请求”的墨绿色圆点，每格十分钟，松开保存，预计刷新保持在发送后五小时。原时间03:33首次左拖到03:30，右拖到03:40；左右方向键也可调整。拖动遵守弹窗的可选范围，取消拖动不保存。

恢复自动

取消手动时间计划，重新依据服务器刷新时间安排发送。没有待执行的手动计划时，该按钮灰淡且不可点击。不会修改服务器额度。额度恢复且五小时使用量为0%时，保留手动计划并等待设定时间。每次检测及发送前，仅当五小时窗口已有使用，且服务器刷新时间达到或超过计划发送时间，才自动取消该计划并恢复自动安排。

重新检测

立即重新读取当前剩余额度和服务器刷新时间，完成后更新页面。此操作不发送小额请求，也不提前执行时间计划；暂停时仍可使用。原有自动定时任务独立运行。

重新连接

首次故障最多尝试5次（含首次），间隔10秒，总时长最多1分钟。仍未恢复时，每20分钟自动尝试一次连接（每小时三次），每次最多1分钟，重启保留等待时间与计划；恢复后先读取额度，下一轮检测处理仍有效的计划。点击“重新连接”可立即重试。非网络错误或结果未知的发送达到上限后仍须手动重连；保留暂停设置和防重复记录。

暂停 / 恢复运行

暂停发送，右上角显示“停止运行”，继续检测额度；恢复后继续执行计划，正常连接运行才显示“后台运行”。暂停不会撤回已经提交的请求。

开机自启动

控制登录 Windows 后是否自动运行。关闭开关不会停止当前后台服务。

错误提示

标题下方仅在出现错误时显示横幅，恢复正常后自动隐藏。提示 CLI 版本过低或接口不兼容时，按横幅中的版本和路径核对实际使用的程序，在 PowerShell 运行 npm install -g @openai/codex@latest，完成后点击“重新连接”；此类错误不会反复重试。

运行状态

卡片并列显示上次、下次检测时间，悬停可查看完整日期；卡片底部显示简要状态，鼠标悬停可查看完整状态或错误原因。

操作与连接日志

悬停整行高亮，时间列与触发记录同宽；显示最近50条操作与连接记录，包括设置、修改、取消计划的原/新时间，以及重新检测、重连、暂停、自启、连接失败和恢复。每分钟检测不会挤掉这些记录；“查看检测明细”可展开最近的原始检测记录。

额度变化统计

细折线显示每分钟剩余额度，点击统计卡标题可平滑滚动到卡片顶部。可切换五小时或周额度、最近一小时/五小时/二十四小时，两个选框会长期记住上次选择，刷新和重新打开页面后自动恢复；悬停查看明细。刻度按范围和数据调整密度，曲线穿过每个真实采样点，曲线始终为墨绿色，快速消耗保留真实陡降，不显示图例或变色。统计复用额度检测，同一分钟以最后一次为准，断网或休眠时留空；重启保留记录。

触发记录

主页只显示最近15条，悬停整行高亮；点击右上角“打开文件夹”查看按月保存的全部触发记录。文件只保留本月、上月、上上月，月初清理，错过时补清理。额度读取显示“已发送请求获取当前额度信息”，不会发送小额模型请求。小额请求单独说明刷新时间未变（相差≤5秒）或已进入五小时倒计时；其他结果按实际核验显示。

日志保留

每月1日按北京时间删除三个月前及更早的月度日志，只保留本月、上月、上上月。月初未运行则在下次运行补清理；失败自动重试。

帮助

在主页打开居中说明弹窗。点击右上角 ×、弹窗外空白处或按 Esc 关闭；后台运行和倒计时不受影响。

时间如何理解

时间轴上方显示服务器额度刷新和预计再次刷新，下方显示发送请求；预计再次刷新按发送时间加五小时计算。时间轴长度固定，等待超过五小时时显示断轴符号，日期和时刻仍完整保留。整点刻度用灰色小字显示，窄窗口自动减少标注。预计再次刷新仅为估计，实际刷新仍以服务器返回为准。断开时保留最后已知时间；临时网络故障自动重连，恢复后按最新额度核验计划。
